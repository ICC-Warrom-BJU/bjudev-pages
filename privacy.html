Kebijakan Privasi

Berlaku sejak: 1 Agustus 2026

1. Tentang aplikasi ini

Content Autopilot adalah alat otomatisasi internal yang digunakan oleh satu operator untuk menjadwalkan dan memublikasikan konten ke akun media sosial miliknya sendiri. Aplikasi ini tidak tersedia untuk pendaftaran publik dan tidak melayani pengguna pihak ketiga.

2. Data yang dikumpulkan

Aplikasi hanya menyimpan data yang diperlukan untuk memublikasikan konten ke akun operator sendiri:

  • Token akses dan token penyegar OAuth untuk akun yang terhubung
  • Pengenal akun (channel ID, user ID) dari akun operator
  • Konten yang dibuat operator: video, judul, keterangan, tagar
  • Metrik performa publik dari unggahan operator sendiri

Aplikasi tidak mengumpulkan data dari pengguna lain, tidak mengakses akun pihak ketiga, dan tidak memiliki mekanisme pendaftaran publik.

3. Cara data digunakan

Data digunakan semata-mata untuk mengautentikasi ke API platform dan memublikasikan konten atas nama operator. Tidak ada data yang dijual, disewakan, dibagikan, atau dipindahtangankan kepada pihak ketiga mana pun.

4. Penyimpanan dan keamanan

Kredensial disimpan terenkripsi dalam basis data privat dengan Row Level Security aktif, hanya dapat diakses oleh proses otomatis milik operator. Berkas video disimpan dalam object storage dan dihapus otomatis setelah 30 hari.

5. Berbagi data dengan pihak ketiga

Aplikasi berinteraksi dengan API resmi Google (YouTube), Meta (Instagram dan Threads), dan TikTok semata-mata untuk memublikasikan konten operator. Tidak ada data yang dibagikan di luar keperluan tersebut.

6. Retensi dan penghapusan

Token disimpan selama akun masih terhubung dan dihapus segera setelah dicabut. Metadata konten disimpan untuk keperluan analitik dan dapat dihapus kapan saja atas permintaan operator.

7. Pencabutan akses

Operator dapat mencabut akses aplikasi kapan saja melalui pengaturan keamanan masing-masing platform. Pencabutan akan langsung menghentikan seluruh akses.

8. Kontak

Pertanyaan mengenai kebijakan ini dapat diajukan melalui alamat kontak yang tercantum pada pendaftaran developer aplikasi.
